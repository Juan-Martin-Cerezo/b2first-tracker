## About blurb (for Devpost / social / directory listings)

> B2 First Tracker is a study platform for the Cambridge B2 First exam built with Python's standard library and vanilla JavaScript (no framework, no build step, no external database). It combines an adaptive daily study plan built from your diagnostic and log, a 4-band Cambridge Writing corrector with quoted sentences and rewrites (DeepSeek), a 14-minute AI Speaking examiner across Parts 1–4 with four Cambridge sample papers, a mandatory British introduction, an AI candidate partner, push-to-talk Gemini STT/TTS, custom tasks, sample papers with paired keys and 74 verified online sources, and a three-chart progress view with a progression matrix.
