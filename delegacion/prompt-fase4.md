## Tarea A — Modo demo en `server.py`

Variable de entorno `B2_DEMO` (`1` = demo). Endpoint nuevo:

```
GET /api/config -> {"demo": true|false, "version": "1.0.0", "ai": true}
```

Con `B2_DEMO=1`, estas rutas responden **403** `{"error":"modo demo: sin cuentas ni sincronización"}`:
`/api/register`, `/api/login`, `/api/logout`, `/api/me`, `/api/users`, y **todo** `/api/progress`
(GET y PUT). El resto (`/`, `/libros.json`, `/diagnostico.json`, `/assets/`, `/files/`,
`/api/ai/writing`) sigue funcionando normal.

Motivo: si el server queda público, nadie debe poder escribir en `data/` ni leer el
progreso del dueño.
